# Meaning vs. Reality

A dated observation journal that installs on your phone like an app. Entries are stored only on the phone it's installed on; nothing is uploaded.

## Put it on GitHub Pages

1. Sign in at github.com and click **New repository**. Name it `meaning-vs-reality`, set it to **Public** (free GitHub Pages needs this; your entries are never in the repo), and click **Create repository**.
2. On the new repo's page click **uploading an existing file**, drag in every file from this folder, and click **Commit changes**.
3. Go to **Settings → Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, Branch to **main** and folder **/ (root)**, then **Save**.
4. Wait a minute or two. Your app will be at `https://YOUR-USERNAME.github.io/meaning-vs-reality/`.

## Install it on your phone

- **iPhone (Safari):** open the link, tap the Share button, then **Add to Home Screen**.
- **Android (Chrome):** open the link, tap the ⋮ menu, then **Install app** or **Add to Home screen**.

Always open it from the home-screen icon, since entries are tied to the installed app.

## Back up

Use **Save backup file** in the app now and then, and keep the file in your cloud drive. **Restore from backup** brings entries back on a new phone.

## Updating the app

Edit the files on GitHub, then change `mvr-v1` in `sw.js` to `mvr-v2` (and so on) so phones pick up the new version.
